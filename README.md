# Excise 720 – Web Application UI

A clean and responsive React + Tailwind CSS interface for managing filings and business details.  
Includes a top navigation bar, mobile-friendly menu, and structured page routing.

---

## 🚀 Tech Stack

- **React.js**
- **React Router DOM**
- **Tailwind CSS**
- **React Icons**

---

## 📱 Features

### ✅ Responsive Navigation  
- Desktop tab navigation  
- Mobile hamburger menu  
- Icon-based actions  

### ✅ Clean UI Components  
- Top navigation bar  
- Reusable layout structure  
- Page-level route management  

### ✅ Modern Styling  
- Tailwind-based gradient text  
- Custom brand color theme  
- Consistent spacing and typography
